## 4. 이번에 새로 넣은 안전장치

**회귀테스트 55건** (`tests/test_regression.py`) — 수집 **전에** 돈다. 실패하면
수집하지 않는다. 네트워크 재시도 정책, 정상 0건 vs 장애 판정, 장비 포함·제외
목록, Telegram 중복 방지, URL 정규화, drift 검사를 고정한다. 실제 네트워크와
번역 모델을 쓰지 않아 0.6초에 끝난다.

**데이터 이상 변동 검사** (`scripts/check_data_drift.py`) — 수집 **후**, Telegram
**전에** 돈다. 결과가 비었거나, 건수·장비 판정이 절반 밑으로 떨어졌거나, 모든
수집원이 동시에 죽었거나, `firstSeenAt`이 사라지면 알림과 커밋을 모두 막는다.

두 번째 것은 이번 작업 중 실제로 필요해졌다. 작업 스크립트를 셸 heredoc으로
돌리다 인용을 빠뜨려 `data/announcements.json`이 빈 파일이 됐고 그대로 커밋됐다.
실행 중이던 워크플로를 즉시 취소했고 Telegram 스텝 전에 멈춰 **발송된 메시지는
없었다.** baseline에서 복원해 작업 전과 바이트 단위로 같음을 확인했다. 같은 일이
다시 나도 이제는 알림·커밋 단계에서 막힌다.

## 6. 남아 있는 문제

**KOTRA — 미해결, 다만 관리 가능.** 러너 IP에 따라 갈린다. 야간 5회 중 3회
성공(60%). 막힌 IP에서는 TCP 연결 자체가 안 되고(사전 확인 후 즉시 포기),
뚫린 IP에서는 연결이 자주 끊기지만 재시도가 전부 흡수한다. 검색형 수집원이라
실패해도 기존 데이터는 유지되므로 화면에서 공고가 사라지지 않는다.

**중국어 제목 로마자 폴백 — 5건.** `YiSi WeiBan Ji`, `GaoQingMINI`, `JiShu`,
`GuangDian`, `ChanXian` 같은 표기가 제목에 남는다. 번역 모델이 처리하지 못한
고유명사·약어가 로마자로 떨어지는 것으로, 오역이 아니라 미번역이다.
`translationIncomplete` 22건은 화면에 "번역 미완료" 배지로 구분 표시된다.

**DGIST 첫 요청 연결 끊김 — 5회 전부.** 매번 첫 요청이 끊기고 재시도 1회로
성공한다. 서버 쪽 일관된 동작으로 보이며 재시도가 흡수하고 있어 조치할 것은 없다.

## 7. 사용자가 지금 추가로 판단해야 하는 항목 (3건)

### (1) KRISS「중적외선 레이저 시스템」을 레이더 범위에 넣을 것인가

공개 규격서까지 확인했다. **장비인 것은 확실하다**(설치·하자보증 있는 독립
장비 1 set). 그런데 정부물품분류는 41 계열(실험실 계측장비)이고, 명시된 용도는
"대체 후보가스의 중적외선 흡수 단면적 정밀 측정"이다. 규격서 어디에도
반도체·디스플레이·웨이퍼·패널이라는 말이 없다.

산업 연결을 시사하는 건 규격 문의 부서가 반도체디스플레이측정그룹이라는 점뿐인데,
No.009에서 "기관·부서명만으로 장비를 인정하지 않는다"고 정해 뒀다. 그 규칙을
이 건에만 푸는 것은 억지 판정이라 하지 않았다.

- **A. 범위에 포함** — 반도체·디스플레이 연구기관이 사는 계측장비도 기회로 본다.
- **B. 범위에서 제외** — 팹·라인에 들어가는 공정·검사 장비만 본다.

어느 쪽이든 필터 한 줄 수정이다. 근거 전문은 `docs/REVIEW-KRISS-63846.md`.

### (2) KOTRA를 현 상태로 둘 것인가

지금은 러너 복불복으로 5회 중 3회 성공이고, 실패해도 기존 데이터가 유지돼
화면에는 티가 나지 않는다. 하루 1회 배치 기준으로 보면 가끔 하루치를 건너뛰는
수준이다.

- **A. 현 상태 유지** — 추가 작업 없음. 권장한다.
- **B. 실행 환경 변경 검토** — self-hosted runner 등. 지시문상 사용자 승인
  사항이라 임의로 진행하지 않았다. 비용과 관리 부담이 생긴다.

### (3) 중국어 제목의 로마자 표기를 손볼 것인가

번역 엔진 교체는 금지돼 있으므로, 가능한 선택지는 용어집 보강뿐이다.
`YiSi`(易思), `JiShu`(技术=기술), `ChanXian`(产线=생산라인), `GuangDian`(光电=광전),
`XianShi`(显示=디스플레이)처럼 **반복해서 나오는 것들**만 용어집에 넣으면
대부분 사라진다.

- **A. 손대지 않는다** — 원문 링크가 있고 "번역 미완료" 배지로 구분되므로
  실무에 지장은 없다.
- **B. 반복 출현 용어만 용어집에 추가** — 작업량은 작지만 기존 번역이 바뀌므로
  제목 변경 0건 원칙과 충돌한다. 진행한다면 별도 지시로 범위를 정하는 편이 낫다.
